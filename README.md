# 🎬 Entertainment Hub

## 📌 About the Project

Entertainment Hub is a front-end web application designed for movie lovers. It provides a simple and attractive platform to explore movies across different genres such as Action, Comedy, Horror, and Love.

The website features a modern dark-themed interface with movie posters, a navigation menu, featured content, and a New Releases section.

## ✨ Features

- 🏠 Home page
- 🎬 Featured movie section
- 🆕 New Releases
- 🔥 Action movies
- 😂 Comedy movies
- 👻 Horror movies
- ❤️ Love movies
- 🔍 Search option
- ▶️ Watch button
- 🎨 Modern dark-themed design
- 🖼️ Movie posters and images
- 🧭 Easy navigation between categories

## 🛠️ Technologies Used

- **HTML5** – For creating the structure of the web pages
- **CSS3** – For styling, layout, colors, navigation, and overall design
